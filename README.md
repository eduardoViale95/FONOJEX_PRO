# FONOJEX_PRO 📱

Landing page moderna y optimizada desarrollada como escaparate digital y plataforma de cotización para una tienda de dispositivos móviles.

## 🚀 Tecnologías utilizadas

El proyecto fue construido utilizando tecnologías web estándar y frameworks de diseño ligero:

* **HTML5:** Estructura semántica del sitio.
* **CSS3 / Estilos personalizados:** Diseño visual adaptado para una experiencia de usuario fluida.
* **JavaScript:** Interactividad y dinamismo en la interfaz.
* **FontAwesome:** Iconografía moderna para botones de contacto y elementos multimedia.
